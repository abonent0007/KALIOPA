## Почему Opera заработала (детали — docs/agents/chatgpt-opera.md)

1. `relay.nova-app.eu` мёртв — TCP-гейт пропускает его за 1.2 с, не 6.5 с.
2. Публичная лента endpoint'ов мертва целиком (EU и US) — discover идёт раньше ленты.
3. Discover отдаёт и мёртвый `.244.47`, и живой `.247.19` — всегда используется
   `-server-selection fastest`, поэтому выбирается живой.
4. Не поднявшийся published endpoint снимается, а не остаётся на 1371.
5. Успешный endpoint кэшируется и проверяется; мёртвый кэш сбрасывается.
6. MTProto исключён из `opera-http` (Opera не пропускает произвольный TCP);
   HTTP-egress разрешён только для `profile` (xray).

## Настройки (temp/routing_settings.json)

```json
"secondary": {"mode": "opera"},
"opera_region": "EU",
"routes": {"ai_apps": "opera", "telegram": "warp", ...}
```

Правки применять только при остановленной Nova: файл перезаписывается при выходе.
