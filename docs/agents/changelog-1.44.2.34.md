# Changelog 1.44.2.34 — подсказки, DoH-звено, статический аудит

Дата: 2026-11-08. Сборка: `KALIOPA 1.44.2.34`.

## Удалённые заглушки и зависимости

- **`httpx`/`h2` в глобальном DoH-режиме больше не нужны.** `nova_doh_service`
  запускал `DohResolver` с `httpx.Client(http2=True)`, а в сборочном Python 3.14
  пакета `h2` нет: клиент падал на создании, исключение глушилось, и режим
  молча уходил в системный DNS. Теперь резолвер поднимает `nova-go dns doh`
  (HTTP/2 даёт Go), а httpx-путь остался только как отладочный (`NOVA_DOH_PY=1`).
- Черновые модули портов узлов (`nova_node_ports`, `nova_node_forward`) из
  рабочего дерева удалены: они не были включены в PAC и не поставлялись.
  Дизайн «слоты + порт 1381 на узел» остаётся в плане, но без мёртвого кода.

## Восстановленные логические звенья

- Глобальный DoH-режим (`NOVA_DOH_GLOBAL=1`): резолвер стартует, адаптеры
  переводятся на 127.0.0.1, при выходе DNS возвращается из снимка. Раньше
  звено рвалось на отсутствующем `h2`.
- DNS-AI (NRPT+DoH): резолвер поднимается только после появления слота,
  правила и процесс живут вместе, `127.0.0.2:53` — если `127.0.0.1:53` занят.
- `_free_loopback_port` и `nova_dns_doh.query` больше не пробрасывают
  исключения наружу: нет порта/сети — «нет ответа», а не падение задания.
- `nova_doh_service.start` закрывает лог-хэндл после запуска (утечка на
  каждый старт).

## Подсказки у кнопок

- Новый `resources/nova_tooltips.py`: одна тёмная плашка, задержка 420 мс,
  привязка к tk-кнопкам, канвасным кнопкам Nova и индикаторам.
- `attach_tree` обходит окна «Профили», «Маршрутизация», настройки генератора и
  импорт; подписи берутся из словаря `BUTTON_HINTS`, для неизвестных работает
  эвристика по глаголу («Подключить…», «Обновить…», «Сохранить…»).
- Явные подсказки: тумблер ПОДКЛЮЧИТЬ/ОТКЛЮЧИТЬ, «Профили», «⚙ Настройки»,
  индикатор слотов (WARP/Opera/Tor) и DNS-AI (градиент/серый/скрыт).
- Кнопки «Сгенерировать», «Настройки…», «Проверить список», подписки, Tor,
  импорт и диалоговые кнопки получают объяснение автоматически.

## Статический аудит и данные

- `python tools/static_analysis.py`: 127 файлов, `unused_imports=0`,
  `unguarded_calls=0`, `unguarded_setup=15` (все — существующие
  `socket.socket`/`requests.Session` внутри try).
- `python tools/import_scan.py`: 135 файлов, `missing=0`.
- `mypy` (линтер/типы) по затронутым модулям: чисто; исправлены Optional-window
  в подсказках, тип `PRESETS` и тип лог-хэндла. Добавлен `tools/typecheck.py` —
  тонкая обёртка, которая молча пропускается, если mypy не установлен.
- Инвентаризация статики: динамическими остаются подписки, списки домен/IP,
  endpoints GeoHide, DoH-имена и точки входа WARP; статическими по замыслу —
  пресеты генератора, белые SNI, seed-стратегии и fallback-адреса Cloudflare.
  Замена последних «на всё динамическое» сломала бы офлайн-старт, поэтому они
  оставлены с явными fallback-ветками.
- Тесты: **335** (+7: шесть на подсказки, один на guard `query`).
