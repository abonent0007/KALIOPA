# Changelog 1.44.2.29 — проверка Custom WARP перед записью

Дата: 2026-11-06. Сборка: `KALIOPA 1.44.2.29`.

- `nova_warp_generator._probe_config`: временный `wireproxy-awg` на свободном
  loopback-порту, HTTP GET `www.gstatic.com/generate_204` через SOCKS5.
- `_socks5_fetch_204`: минимальный SOCKS5-клиент на сокетах, без curl.
- `_durable_endpoints`: хост из скана сохраняется, нестандартный порт (955, 3581)
  заменяется на `2408` — на случайных портах рукопожатие проходит, а данные
  перестают идти через секунды.
- Двойная проба с паузой 2 с: «моргнувшая» сессия профилем не становится.
- `generate_custom_one`: параметры `wireproxy_path`/`probe`, до 3 прикрытий
  `I1` на каждую из 2 точек входа, запись только после двух успешных проб;
  в результате `probed` и `attempts`.
- Причина сбоев: случайный `I1` DPI дропает вместе с рукопожатием; без `I1`
  WARP в РФ не поднимается. Подтверждено подменой `I1` между рабочим и
  нерабочим профилями.
- Тесты: 298 (6 новых).
