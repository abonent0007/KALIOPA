# DNS-разблокировка: GeoHide, DNS-AI, comss

Проверено 2026-10-31 на живом сервисе (страница GeoHide, публичный отчёт HetrixTools).

## Что публикует GeoHide

Шапка hosts-файлов и `hostPools` на самом сайте дают разные вещи: hosts-файл
перечисляет **все** адреса сервиса (16 на 20.10.2026), а `hostPools` — рабочий
пул по регионам:

| Регион | top | extra | DoH |
|---|---|---|---|
| RU | `193.233.112.67`, `193.233.112.68` | — | `https://geohide.ru/dns-query` |
| EU | `217.60.245.219`, `217.60.245.233` | `31.25.239.132`, `143.20.64.192`, `2.27.118.34` | `https://eu.geohide.ru/dns-query` |
| US | `192.255.159.240`, `192.255.159.241` | `192.3.233.253`, `107.175.76.134` | `https://us.geohide.ru/dns-query` |

Остальные протоколы: DoT/DoQ — `tls://` и `quic://` на том же хосте; UDP — адреса пула.
Списки доменов `ru/eu/us/domains.txt` **побайтово одинаковые** (375 доменов,
sha256 `e93fe226…`): регион меняет адреса DNS и прокси, а не набор сайтов.
Обновление списка — 20.10.2026 04:30.

Смысл регионов по описанию сервиса: `RU` — DNS в России, прокси через Россию в
Европу и США; `EU` — DNS и прокси только в Европе; `US` — DNS и прокси только в
США. Это Smart DNS для доменов из списка, а не полноценный VPN: IP-адрес
пользователя на `2ip.io` он не меняет.

## Аптайм (HetrixTools, 2026-10-31)

| Адрес | DNS | Proxy |
|---|---|---|
| `37.230.192.51` | 99.76 % | — |
| `159.194.200.33` | 99.59 % | 99.76 % |
| `193.233.112.68` | 90.59 % | 90.62 % |
| `193.233.112.88` | 87.11 % | 87.12 % |
| `193.233.112.67` | 82.10 % | 82.14 % |

Поэтому `resources/nova_dns_endpoints.py` сортирует адреса по этому аптайму
(`UPTIME_RANK`), а не по порядку в файле: Windows пробует серверы правила
по порядку.

## Как адреса попадают в Nova

1. `resources/nova_dns_endpoints.py` тянет hosts-файл с GitHub
   (`Internet-Helper/GeoHideDNS`, обновляется сервисом), разбирает блок
   «Эти IP-адреса принадлежат GeoHide DNS», сортирует по аптайму, кэширует
   `temp/dns_endpoints.json` на 24 ч.
2. `nova.pyw` строит NRPT-каскад `dns-ai → comss → geohide`, беря пул GeoHide
   из кэша (или зашитого fallback) — сеть на старте не трогается.
3. Любая ошибка сети/формата оставляет прежний кэш или fallback.

## Ограничения

- Прямой запрос к `geohide.ru` из RU отдаёт 503; страница и hosts-файлы
  открываются через Opera-прокси Nova (1371). GitHub-копия доступна напрямую,
  поэтому она и выбрана основным источником.
- `vpn-api.proton.me` через обычный DNS отдаётся как NXDOMAIN (подмена), а
  через DoH и GeoHide резолвится. Для Proton API это значит: либо прокси
  (резолв на стороне прокси), либо DoH.

## DNS-AI: проверено 2026-10-31

Сервис жив, но со своей спецификой:

- **Только DoH, HTTP/2 обязателен.** На HTTP/1.1 — `505` («implements RFC 8484 …
  requires HTTP/2 in accordance with section 5.2»). JSON-API (`?name=…&type=A`)
  не поддерживается — `400 DoH unable to decode BASE64-URL`. Работает только
  wireformat: `?dns=<base64url>` + `accept: application/dns-message`.
- **UDP/53 молчит by design** — таймаут на всех адресах. Поэтому NRPT Nova его
  не использует: правила строятся по UDP-доступности.
- Адреса из upstream serial 7 подтверждены: `dns.dns-ai.ru` → `45.151.102.219`
  (+ IPv6 `2a00:b700:5::3:62`, `2a12:5940:d4ef::219`); в каскаде —
  `194.87.196.13` и `45.151.102.219`.
- Ответы через DoH (httpx, HTTP/2): `chatgpt.com` → `199.189.255.234` (218 мс),
  `gemini.google.com` → `193.233.112.88` (80 мс), `claude.ai` →
  `199.189.255.234`, `example.com` → 2 записи. Для Gemini это тот же адрес,
  что отдаёт GeoHide.
- `199.189.255.234` с SNI `chatgpt.com` отдаёт Cloudflare-челлендж («Enable
  JavaScript and cookies to continue»), а не страницу ChatGPT: это не обходной
  прокси, а тот же Cloudflare-край.

**Антивирус.** На этой машине запросы к `dns.dns-ai.ru` блокировались
антивирусом: до исключения — таймауты, после отключения — HTTP/2 отвечает за
40–220 мс. Если DNS-AI нужен, домен надо добавить в исключения.

**Вывод.** Для NRPT-разблокировки остаются GeoHide (30 из 32 имён) и comss
(22 из 32). DNS-AI подключается только как системный DoH-резолвер с шаблоном
`https://dns.dns-ai.ru/dns-query` (его регистрирует штатный клиент); вручную
вписанные IP без шаблона бесполезны.
