# Changelog 1.44.2.35 — повтор DNS-AI после подключения

Дата: 2026-11-08. Сборка: `KALIOPA 1.44.2.35`.

- `_schedule_dns_doh_retry` больше не сдаётся после одной попытки: цикл до
  шести раз ждёт слот, вызывает `setup_nrpt_dns_unblock` и проверяет, что
  резолвер действительно поднялся. Раньше при холодном старте (туннель ещё
  поднимается) правила снимались и больше не ставились до перезапуска.
- Ветка «резолвер не поднят повторно» теперь тоже планирует повтор, а не
  только снимает правила.
- Причина: лог 01:41 — кэш поддержки (16 имён) прочитан, старт резолвера
  упал на таймауте DoH, повтор не был запланирован.

Проверки: 335 тестов, `typecheck` (5 модулей), `static_analysis` (0 unguarded
calls), `import_scan` (0 missing). После установки: PAC 200, SOCKS 204,
HTTP 204; резолвер поднимается, как только появляется слот.
