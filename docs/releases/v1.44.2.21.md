# KALIOPA 1.44.2.21

Приватная сборка на базе **Nova 1.44.2** (upstream: [confeden/Nova](https://github.com/confeden/Nova)).
Отображаемое имя — **KALIOPA**; exe, папка установки, мьютекс и AppData остаются
`Nova`, чтобы обновления, хелперы и существующая установка продолжали работать.

## Установка

- Windows 10/11 x64.
- Запустить `KALIOPA_Setup_1.44.2.21.exe`; установщик без подписи, SmartScreen
  может предупредить.
- Для WinDivert/WFP приложение само запросит права администратора.
- Поверх существующей Nova ставится как обновление; профили и `temp/` не удаляются.
- SHA-256: `1553E8C6034C575B628FE4B08FE8159412735C1F7710BCC346E7529E79988C49`.

## Что нового в 1.44.2.19–1.44.2.21

### Транспорт и узлы
- **Xray-core 26.10.31** — срочные security-фиксы (отзыв скомпрометированных CA,
  отключение уязвимого MPTCP), XHTTP/REALITY и Windows-фикс.
- **quic-go 0.65.0**, **usque 4.2.1** — меньше `PROTOCOL_VIOLATION`, pacing и
  datagram/HTTP3-фиксы; MASQUE проверен живьём.
- **opera-proxy 1.31.0** — Go 1.27.3, обновлённые CA; сохранены `-fake-SNI`,
  `-override-proxy-address`, `-api-proxy`.
- **warp-plus 1.2.6** + Nova-патч динамических local address в netstack.
- **wireproxy-awg 1.0.18** — AmneziaWG v3, `--configtest` на живом профиле.
- **Tor Expert Bundle 16.0** — tor 0.4.9.15, lyrebird 0.9.0; sha256 сверен с
  подписанным `sha256sums-signed-build.txt`.
- **Python-зависимости** — requests 2.34.2, urllib3 2.8.0, certifi 2026.10.23,
  httpx 0.28.1, Pillow 13.0.0, cryptography 50.0.2.

### ChatGPT и Telegram
- ChatGPT и Gemini открываются через **Opera EU** (PAC `ai_apps=opera`).
- Opera: TCP-гейт мёртвых relay, discover раньше ленты, `fastest`, кэш живого
  endpoint, backoff `60·2^n`.
- Telegram: native MTProto только через WARP-socks; `opera-http`/Tor-HTTP
  исключены, `502` = 0.

### Динамическая личность релея
- `API_RELAY_KEY_VERSION` удалён; версия логина подбирается под ключ из релизов
  upstream и проверяется пробой через WARP, кэшируется.

### Брендинг и окно
- OBNOVA → **KALIOPA**: заголовок, сплэш, трей, меню, диалоги, установщик.
- Окно равно размеру фона (967×540), без полос; UI масштабируется, кнопки
  считаются от центра и углов фона.

## Чем отличается от upstream Nova

| Область | Upstream | KALIOPA |
|---|---|---|
| Имя | Nova | KALIOPA (exe/папки — Nova) |
| ChatGPT | зависит от выхода | Opera EU + PAC `ai_apps=opera` |
| Opera | published endpoints первыми | discover + fastest, TCP-гейт relay, кэш |
| Релей | логин из `CURRENT_VERSION` | версия подбирается под ключ |
| Окно | 360×270 | размер фона, UI scale |
| Автообновление | включено | отключено, только списки/профили |
| Python/Go/Tor | по релизу | обновлены вручную 2026-11-03 |

## Ограничения

- Opera US на 2026-11-03 отвечает, но ChatGPT через него получает 403; рабочий
  регион — EU. AS-регион ленты не работает (API 801).
- Публичные VLESS-узлы в этой сети почти все мертвы; карантин отсеивает их.
- Proton WireGuard handshake блокируется провайдером.
- Rust-крейты не обновлены: нет `link.exe`/MSVC Build Tools (UAC).
- Официальный `connect-ip-go v0.7.0` несовместим с API usque v4.2.1; оставлен
  локальный снимок + патч.

## Безопасность

Репозиторий и релиз **приватные**. В установщике нет личных профилей Proton,
MASQUE, Custom, подписок и `.runtime`, но есть штатный relay-ключ и общие
WARP-сиды — как в upstream. Не переключать репозиторий в публичный.
