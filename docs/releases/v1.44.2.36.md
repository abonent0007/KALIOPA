## Что нового

### Gemini снова получает не-RU выход

Основной WARP-слот выходит в Россию (`loc=RU`), а вторичный Opera не поднимался:
`discover` отвечал 801/таймаутом, порт 1371 был закрыт, и PAC уводил ИИ-домены
на WARP с RU-выходом. Причины и правки:

- **Лента Opera-точек качалась напрямую из России**, где GitHub заблокирован:
  `urllib` всегда получал пустоту, и менеджер шёл в мёртвый EU-пул. Теперь
  лента загружается через живой слот (WARP SOCKS 1370 / Opera 1371), замер —
  3.2 с; `US` по-прежнему означает пул `AM`.
- **US/AM не получал WARP-транспорт**: машина состояний предлагала
  `EU-over-WARP` только для EU, а выбранный US бесконечно повторял direct.
  Теперь US/AM переходит на `-proxy socks5h://127.0.0.1:1370` так же, как EU.
  Живой замер: `-country AM` через WARP → HTTP 200, выход не RU; EU → NL/AMS.

После подключения вторичного слота PAC направляет `ai_apps` на 1371, и Gemini
видит европейский/американский выход вместо российского.
