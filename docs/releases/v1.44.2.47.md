# KALIOPA 1.44.2.47

Приватная сборка на базе **Nova 1.44.2**. Отображаемое имя — **KALIOPA**;
exe, папка установки, мьютекс и AppData остаются `Nova`.

## Установка

- Windows 10/11 x64, установщик без подписи.
- Поверх существующей Nova; профили и `temp/` не удаляются.
- SHA-256: `PUBLISH_ME`.
- Размер: 0 байт.

## Что нового

### Фон меняется во время подключения

Пока Nova подключается (на главном экране «ПОДКЛЮЧЕНИЕ»), фон окна каждые
**3 секунды** чередуется между `img/background.png` и `img/background2.png`.
Как только соединение установилось (или остановлено) — остаётся основной фон.

Оба файла 967×540, вшиваются в сборку (`embedded_assets`), второй фон
подхватывается и в замороженной сборке.

### Закрытие окна — в трей

Крестик окна (в том числе в развёрнутом виде) больше не завершает программу:
окно сворачивается в трей. Выход из программы остался только через контекстное
меню трея («Открыть» / «Выход»).
