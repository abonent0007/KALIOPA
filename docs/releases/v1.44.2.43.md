# KALIOPA 1.44.2.43

Приватная сборка на базе **Nova 1.44.2**. Отображаемое имя — **KALIOPA**;
exe, папка установки, мьютекс и AppData остаются `Nova`.

## Установка

- Windows 10/11 x64, установщик без подписи.
- Поверх существующей Nova; профили и `temp/` не удаляются.
- SHA-256: `58C8F3C283470A29F7E190B748F5D9DD5F81FF5B110E881A9D394930CB130019`.
- Размер: 89 333 249 байт.

## Что нового

### Страна выхода в генераторе AWG (Custom AWG)

В «Настройки…» добавлена строка «Страна выхода». Каталог стран —
`temp/warp-countries.json`, правится кнопкой «Править…» (название, хост,
порт, ISO). Выбор страны подставляет её `host:port` в точку входа; «Любая» —
обычный авто-скан Cloudflare.

После успешной проверки профиль получает измеренный выход
(`http://ip-api.com/json` через временный SOCKS): `observed_ip`/`observed_loc`
в `temp/warp-custom-meta.json` и в сообщении о генерации.

### Раздел «DNS» в окне «Профили»

Новая вкладка: каталог из 10 резолверов (Cloudflare, Google, Quad9, dns-ai,
malw, bezmezhau, geohide, geodema, mafioznik, comss) с проверкой реальным
UDP-запросом («✓ 39 мс» / «✗ нет ответа»), «Проверить все», свой резолвер.

Ниже — «DNS по маршрутам»: назначение резолвера доменным группам PAC
(ru, eu, ai_apps, youtube, telegram, whatsapp, discord, exclude, browser).
Назначение хранится в `temp/dns-routes.json` и применяется построителем
NRPT-правил: выбранный резолвер подменяет каскад dns-ai → comss → geohide
для имён своей группы.

### Чистка

Удалён мёртвый источник `Delta-Kronecker REALITY` (404) и мёртвый Tor-фолбэк
`Delta-Kronecker/Tor-Bridges-Collector` (404 на обоих зеркалах); локально
удалены 118 его профилей.
