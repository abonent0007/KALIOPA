# KALIOPA 1.44.2.48

Приватная сборка на базе **Nova 1.44.2**. Отображаемое имя — **KALIOPA**;
exe, папка установки, мьютекс и AppData остаются `Nova`.

## Установка

- Windows 10/11 x64, установщик без подписи.
- Поверх существующей Nova; профили и `temp/` не удаляются.
- SHA-256: `66E319560D6DF9EC66FD21E05E79E16A02B84B943919CA23A6E4E86BE1E580E0`.
- Размер: 90 471 854 байт.

## Что нового

### Конструктор AWG 1.5 / 2.0 / 3.0 / 3.1

Перенесён открытый генератор https://awgconfig.com (HereIamGosu/amnezia-config-gen,
**AGPL-3.0**) — в `resources/nova_awg3.py`:

- профили legacy/awg2/awg3/awg31, WARP-safe ограничения (`S1..S4=0`,
  `H1..H4=1..4`, RandomTrailers и HeaderProtection запрещены);
- случайные тайминги AWG 3.x (Rekey/Reject/Keepalive/Handshake) и
  ContentPaddingAddition;
- CSP-протоколы I1: static/sip/stun/dns/dtls/quic + цепочки I2..I5
  (`<r>/<t>/<b>`), пул проверенных бинарных payload Cloudflare WARP.

Окно: **Профили → Custom AWG → «Конструктор…»** — профиль, точка входа
(авто-скан / hostname / вручную), порт, количество, IPv6, DNS, CSP-протокол,
цепочки I2..I5, DisableCookies (только 3.1). Файлы `AWG3_*.conf` пишутся в
`profiles/Custom`, первый выбирается и подключается.
