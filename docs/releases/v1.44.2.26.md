# KALIOPA 1.44.2.26

Приватная сборка на базе **Nova 1.44.2**. Отображаемое имя — **KALIOPA**;
exe, папка установки, мьютекс и AppData остаются `Nova`.

- Windows 10/11 x64, установщик без подписи.
- Поверх существующей Nova; профили и `temp/` не удаляются.
- SHA-256: `80ECB5A3759634B700510A90280DA545C97D3FB4909AAC37A21E267577EB34BB`.
- Размер: 111 104 111 байт.

## Что нового

### Резервные публичные списки

Добавлены два необязательных источника:

- `vpn-free-russia/main/verified_configs.txt` — 500+ проверенных ссылок
  VLESS/VMess/Trojan/SS;
- `vpn-free-russia/main/ru_configs.txt` — компактный RU-список.

Потолок профилей поднят с 600 до 900, чтобы оба списка помещались рядом с
основными VLESS-источниками. Публичные узлы нестабильны и видят SNI —
это резерв, не маршрут для личных аккаунтов.

### Окно профилей: кэш файловой части

Окно обновляется каждые 1.5 с, но 550–900 файлов профилей, статистика и
подписки перечитываются только когда меняются их mtime/size. Статусы
по-прежнему обновляются каждый тик. Это убирает постоянный скан диска и
строку «Nova не отвечает» на большом списке.

### Тёмная тема как в Windows 11

Окно «Настройки маршрутизации» больше не зелёное: нейтральные поверхности
`#202020/#2B2B2B`, белый текст, системный синий акцент для выбранных
переключателей и hover. Заголовок окна остаётся тёмным через DWM.

### Фоновый PowerShell

`NovaTunnelGuard` больше не показывает консоль каждые 5 минут: задача
запускает `wscript.exe //B` → VBS, который стартует PowerShell с
`-WindowStyle Hidden` и окном 0. Сама задача помечена Hidden. Резервная копия
XML — `C:\lib\backup-nova\NovaTunnelGuard-*.xml`.
