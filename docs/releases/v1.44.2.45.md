# KALIOPA 1.44.2.45

Приватная сборка на базе **Nova 1.44.2**. Отображаемое имя — **KALIOPA**;
exe, папка установки, мьютекс и AppData остаются `Nova`.

## Установка

- Windows 10/11 x64, установщик без подписи.
- Поверх существующей Nova; профили и `temp/` не удаляются.
- SHA-256: `PUBLISH_ME`.
- Размер: 0 байт.

## Что нового

### Автоматизация вместо ручного ввода

- **Страны определяются сами.** «Настройки…» → «Найти страны…» (и один раз
  автоматически при пустом каталоге): скан Cloudflare, подъём каждого туннеля и
  замер страны выхода через `ip-api`. Результат пишется в
  `temp/warp-countries.json`; хосты вручную вводить не нужно.
- **DNS проверяется сам.** При входе на вкладку «DNS» выполняется
  «Проверить все» (один раз на состав каталога); назначения с диска
  перечитываются при каждом открытии вкладки.
- Окно «Профили» при первом открытии сразу шире 900px.

### Надёжность

- Диспетчер действий больше не падает целиком из-за отсутствующего обработчика
  (таблица `_ACTION_METHODS`/`_ACTION_JOBS`); регрессионный тест это
  фиксирует.
- Адреса DNS резолверов резолвятся живым DNS-запросом, статический список —
  fallback.
- SOCKS5-рукопожатие вынесено в общий `_socks5_handshake` (было две копии).
- Выбор `dns-ai.ru` для маршрута ведёт на локальный DoH `127.0.0.1` (у сервиса
  нет UDP/53).

### Удалённые заглушки

- Действие `dns_test` из подписей и диспетчера (осталось `dns_test_all`).
- Мёртвая ссылка `_on_dns_test_selected` (источник падения всех кнопок
  в 1.44.2.43).

## Проверки

- **399 тестов OK**, `py_compile`, статанализ без нарушений.
- Живой прогон `discover_countries`: найдено среди точек Cloudflare —
  `🇷🇺 Россия` (162.159.195.29:2408), ~100 с на 6 кандидатов.
- Headless-прогон Tk: авто-проверка DNS заполняет статусы, диалог настроек
  открывается.
