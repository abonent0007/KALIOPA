# KALIOPA 1.44.2.44

Приватная сборка на базе **Nova 1.44.2**. Отображаемое имя — **KALIOPA**;
exe, папка установки, мьютекс и AppData остаются `Nova`.

## Установка

- Windows 10/11 x64, установщик без подписи.
- Поверх существующей Nova; профили и `temp/` не удаляются.
- SHA-256: `978BF79603206FCD5F52C74C7B564CB36F31173CCD35BDF344EDAD1DB6DEF73A`.
- Размер: 89 334 841 байт.

## Что нового

### Исправление: не работали кнопки действия (включая «Настройки…»)

В диспетчере действий окна «Профили» остался несуществующий обработчик
`_on_dns_test_selected`. Словарь обработчиков строится целиком, поэтому **любая**
кнопка действия падала с `AttributeError` — не открывались «Настройки…»
Custom AWG, «Проверить все», «Применить» и прочие.

- диспетчер переписан на таблицу `действие → метод` (`_ACTION_METHODS`,
  `_ACTION_JOBS`), отсутствующий метод больше не роняет все кнопки;
- добавлен регрессионный тест: у каждого действия вкладок должен быть
  метод окна.

### Мелкие правки

- редактор стран принимает кириллические названия («Финляндия» → id
  `finlyandiya`), а не отбраковывает их;
- «Проверить все» в DNS идёт параллельно, а не по очереди;
- выбор `dns-ai.ru` для маршрута ведёт на локальный DoH-резолвер
  `127.0.0.1` (у сервиса нет UDP/53).
