## Что нового

### Подсказки у каждой кнопки

Наведите курсор на кнопку — через 0.4 с появится тёмная плашка с объяснением.
Покрыты главное окно (тумблер, «Профили», «Настройки», индикаторы слотов и
DNS-AI), окно «Профили» (подключение, проверки, генератор WARP, подписки, Tor,
импорт), «Маршрутизация», настройки генератора и диалог импорта. Для подписей
вне словаря работает эвристика по глаголу, поэтому безымянных кнопок не
остаётся.

### Глобальный DoH-режим починен

`nova_doh_service` больше не зависит от `httpx`/`h2`: резолвер поднимает
`nova-go dns doh`, который сам держит HTTP/2. Раньше в сборочном Python 3.14
не было `h2`, исключение глушилось, и режим молча не работал. Теперь
`NOVA_DOH_GLOBAL=1` действительно переводит DNS на локальный DoH с возвратом
адаптеров из снимка при выходе. DNS-AI (NRPT) остаётся основным путём.

### Мелкие исправления цепочки

- DNS-AI-резолвер поднимается только после слота и останавливается вместе с
  правилами; при занятом `127.0.0.1:53` уходит на `127.0.0.2:53`.
- Ошибки сокета в проверке профиля и в запросе к резолверу больше не роняют
  задание: «нет ответа» вместо исключения.
- Закрыт лог-хэндл DoH-резолвера (утечка на каждый старт).
