## Что нового

### «Сгенерировать» в Custom AWG

В группе **Custom AWG** появилась кнопка **«Сгенерировать»**. Один клик:

1. использует уже зарегистрированную локальную WARP-личность (или регистрирует новую
   через `nova-go warp`, без сторонних web-API);
2. сканирует точки входа Cloudflare и выбирает ближайшую рабочую (при пустом
   скане — публичный fallback);
3. собирает **AWG 2.0**-профиль: `MTU 1280`, DNS `1.1.1.1`, `PersistentKeepalive 25`,
   случайные `Jc/Jmin/Jmax`, `I1` из QUIC Initial (SNI из белого списка);
4. пишет `profiles/Custom/WARPgen_custom_NN.conf`, не трогая `WARPgen_*` в
   `AWG Cloudflare` и другие Custom-профили;
5. сохраняет выбор профиля и сразу применяет его через `apply_selection_now`
   (если Nova подключена).

Приватный ключ генерируется локально. `warp-api.cfd` и llimonix не используются:
их API отдаёт готовый private key, а `warp2.llimonix.pw` вообще не имеет
публичного API.

### Ограничения

- Пока это AWG 2.0. AWG 3.0/3.1 из `warp-generation` не включены: текущий
  `wireproxy-awg`/`nova_profiles` не знает `ContentPaddingAddition`,
  `MaxHandshakeAttempts` и другие поля 3.x.
- Окно выбора параметров (endpoint, DNS, MTU, keepalive, I1 SNI, Jc/Jmin/Jmax)
  будет следующим шагом; сейчас используются проверенные оптимальные значения.
- Публичные WARP-точки общие и могут быть перегружены; сканер и fallback
  выбирают только доступные.
