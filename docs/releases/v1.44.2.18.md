# KALIOPA 1.44.2.18

Приватная сборка на базе **Nova 1.44.2** (upstream: [confeden/Nova](https://github.com/confeden/Nova)).
Отображаемое имя — **KALIOPA**; exe, папка установки, мьютекс и AppData остаются
`Nova`, чтобы обновления, хелперы и существующая установка продолжали работать.

## Установка

- Windows 10/11 x64.
- Запустить `KALIOPA_Setup_1.44.2.18.exe`. Установщик без подписи, SmartScreen
  может показать предупреждение.
- Для WinDivert/WFP приложение само запросит права администратора.
- Поверх существующей Nova ставится как обновление; профили и `temp/` не удаляются.
- SHA-256: `D6961FDE5FDC9B91DC05DEB95DBBA41C88EFCD2F754EF03CAF8212EB8B262854`.

## Что сделано в форке

### Брендинг и главный экран
- OBNOVA → **KALIOPA**: заголовок окна, сплэш, трей, меню, диалоги,
  `MyAppName` установщика, имя устройства WARP (`KALIOPA PC`).
- Окно подстраивается под `background.png` (967×540), фон заполняет клиентскую
  область без полос; UI масштабируется вместе с окном.
- Кнопки считаются от центра и углов фона: «Обновить до» — правый верх,
  «Профили/Настройки/Лог» — правый низ, индикаторы — левый низ.

### ChatGPT и Gemini
- ChatGPT открывается в обычном браузере через **Opera EU** (системный PAC:
  `ai_apps → opera → 127.0.0.1:1371`).
- WARP и Tor получают от OpenAI 403; Opera-выход SE проходит Cloudflare-проверку
  в headed-браузере.
- Починен запуск Opera: мёртвые relay пропускаются по TCP за 1.2 с, discover идёт
  раньше опубликованной ленты, всегда используется `-server-selection fastest`,
  рабочий endpoint кэшируется, мёртвый published-endpoint снимается.
- MTProto никогда не отправляется через `opera-http`/Tor-HTTP: Opera не пропускает
  произвольный TCP (CONNECT к DC Telegram висит, порт 25 — 502).

### Telegram-релей
- `502 tor protocol violation` — 0: Tor-HTTP исключён для MTProto.
- Маршрут выбирается по EWMA скорости; `direct` всегда последний.
- `traffic` — одна строка на маршрут раз в 60 с, `probe diag` — не чаще 30 с.
- Native MTProto идёт через WARP-socks.

### Динамическая личность релея
- Удалена константа `API_RELAY_KEY_VERSION`.
- `nova_relay_identity` берёт версии из релизов upstream, проверяет ключ пробой
  через WARP и кэширует рабочую версию (`temp/relay_identity.json`,
  `profiles/opera_relay.version`).
- На 2026-11-01 ключ из upstream 1.44.2 принимает логин **1.44.1**; `1.44.2`
  получает 407. Выбор больше не зависит от версии форка.

### DNS и узлы
- Локальный DoH-резолвер (`NOVA_DOH_GLOBAL=1`) со снимком и восстановлением DNS
  адаптеров; при занятом порту откат, а не «тихий» перевод системы на мёртвый DNS.
- NRPT-разблокировка AI-доменов сохранена.
- Proton: до 3 конфигов на узел (`-p2`, `-p3`, порты 443/1194/4500 + junk),
  `NOVA_PROTON_VARIANTS=0` выключает.
- VLESS: TCP pre-flight новых узлов подписки (2 с, 8 потоков); при сбое пробы
  подписка не блокируется (fail-open). TLS-проба — опция.
- Добавлены подписки kort0881, MhdiTaheri, ALIILAPRO; пин-фильтр отсеивает
  «ядовитые» узлы.

### Стабильность и обслуживание
- Opera: экспоненциальный backoff `60·2^n` до 30 минут после неудачных
  перезапусков.
- Уборка осиротевших `winws_test` старше 10 минут.
- Установка поверх — `tools/install_overlay.ps1` (обход `code 5` на locked DLL).
- Автообновление самой программы отключено; обновляются только списки и профили
  из стоковых источников.

## Чем отличается от оригинала

| Область | Upstream Nova | KALIOPA |
|---|---|---|
| Имя | Nova | KALIOPA (exe/папки — Nova) |
| ChatGPT | зависит от версии/выхода | Opera EU + PAC `ai_apps=opera` |
| Opera | published endpoints первыми | discover + fastest, TCP-гейт relay, кэш живого endpoint |
| Релей | логин из `CURRENT_VERSION` | версия подбирается под ключ |
| Окно | фиксированное 360×270 | размер фона (967×540), UI scale |
| Автообновление | включено | отключено, только списки/профили |
| Установка | Inno Setup | + overlay-скрипт на locked-файлы |
| Подписки | штатные | + kort0881, MhdiTaheri, ALIILAPRO |

## Ограничения

- Opera US (`77.111.246.x`) на 2026-11-01 мёртв; рабочий регион — EU.
- Публичные VLESS-узлы в этой сети почти все мертвы (40/40 через `nova-xray`);
  карантин отсеивает их после первых попыток.
- Proton WireGuard handshake блокируется провайдером; варианты портов не помогают.
- ChatGPT зависит от живого Opera-выхода: если Opera недоступна, PAC уйдёт на
  WARP, где OpenAI отдаёт 403.

## Безопасность

Репозиторий и релиз **приватные**. В установщике нет личных профилей Proton,
MASQUE, Custom, подписок и `.runtime`, но есть штатный relay-ключ и общие
WARP-сиды — как в upstream. Не переключать репозиторий в публичный и не передавать
доступ к релизу без необходимости.
