# KALIOPA 1.44.2.46

Приватная сборка на базе **Nova 1.44.2**. Отображаемое имя — **KALIOPA**;
exe, папка установки, мьютекс и AppData остаются `Nova`.

## Установка

- Windows 10/11 x64, установщик без подписи.
- Поверх существующей Nova; профили и `temp/` не удаляются.
- SHA-256: `F9995B1ABD95A82CD2CF2B257EE80F533D8CA2917D79AB9752F7FB01194ED861`.
- Размер: 89 332 811 байт.

## Что нового

### Окна приведены к одному размеру, кнопки всегда на экране

- Единая минимальная ширина модальных окон «Профилей» — **640px**
  (`PROFILE_DIALOG_WIDTH`): настройки генератора и редактор стран больше не
  открываются разной ширины, а «Править…»/«Найти страны…» перенесены на отдельную
  строку и не обрезаются.
- Вкладка **DNS**: список резолверов, свой DNS и 9 маршрутов теперь скроллятся
  внутри области фиксированной высоты — кнопки «Проверить все / Применить /
  Сбросить» остаются видимыми на любом экране.
- Окно «Профилей» стабильно открывается ~900×650 (шире 900px, высота по содержимому).

## Известное ограничение (честно)

Выбор страны в AWG не может дать Финляндию/Норвегию/США из текущей сети:
замер `https://www.cloudflare.com/cdn-cgi/trace` для точек Cloudflare даёт
`loc=RU` (colo ARN) — WARP из этой сети выходит только в российский гео-адрес.
«Найти страны…» определяет реально доступные; для других стран нужны свои
географические серверы («Править…»).
